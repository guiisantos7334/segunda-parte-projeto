# Aço Sustentável

Landing page desenvolvida como projeto da formação Liga STEAM, utilizando HTML, CSS e JavaScript para apresentar conceitos de sustentabilidade na indústria do aço de forma moderna, informativa e interativa.

## Sobre o projeto

O projeto tem como objetivo conscientizar os usuários sobre a importância do aço sustentável e das práticas ambientais responsáveis adotadas pela indústria moderna.

A aplicação apresenta conteúdos relacionados à sustentabilidade, inovação e economia circular, utilizando recursos visuais e interativos para tornar a experiência mais dinâmica.

## Funcionalidades

* Navegação por seções com menu interativo;
* Galeria de imagens ilustrativas;
* Seção de valores sustentáveis;
* Curiosidade interativa com JavaScript;
* Quiz sobre aço sustentável;
* Estatísticas de sustentabilidade;
* Formulário de contato com feedback visual;
* Layout responsivo para diferentes dispositivos;
* Estrutura semântica utilizando HTML5.

## Tecnologias Utilizadas

* HTML
* CSS
* JavaScript
